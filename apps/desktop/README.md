# ScreenParty Desktop (Planejado)

Este diretório está reservado para a versão Desktop nativa do ScreenParty (baseada em Electron ou Tauri com captura nativa de áudio do sistema).

Conforme o planejamento da **Etapa 1 (V0.1)**, o foco é a plataforma Web funcional com `getDisplayMedia` no navegador (Chrome/Edge), LiveKit e backend Node.js.
